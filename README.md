# 组件规范与无障碍说明编辑台（sologsb-1028）

面向设计系统维护者的组件契约编辑台。项目从零搭建，不是单页占位稿；组件、属性、状态、键盘行为、读屏说明、禁用场景和代码示例均使用真实数据模型，并自动保存到浏览器 `localStorage`。

## 功能

- 组件目录与全文搜索：可搜索组件名称、属性、键盘行为、读屏说明和示例代码；**搜索只读取评审通过后的最终生效结论**，草稿、排队中和评审中的内容不会命中。
- 分组编辑器：概述、属性与状态、无障碍、关联示例、发布评审、版本与迁移六个工作区。
- 规范校验：检测重复属性、缺少键盘/读屏说明、空示例、失效属性引用和交互契约变化。
- 失效传播与迁移：修改交互签名、删除属性或更新组件契约后，关联示例会标记为待迁移；迁移操作可清理已删除属性引用并更新版本。
- 发布窗口与评审队列：
  - 每个发布窗口 **3 个评审名额**，受理即占用（通过/评审中/驳回都占名额），满员后送审按提交顺序进入 FIFO 等待队列。
  - 送审前按当前契约重新核验：重名/空属性、缺少键盘或读屏说明、示例为空/引用已删除属性/已标记失效/基于旧版本，或同一组件已有在途评审时，**整次拒绝**，契约草稿与失败原因均保留在「发布评审」页。
  - 送审时冻结契约快照，之后修改组件不会覆盖在评或已确认结论。
  - 窗口切换时未开始项按顺序顺延到新窗口受理；评审中项留在旧窗口出结论。
  - 排队期间同一组件再次修改，会自动撤回未开始旧项并把新冻结契约排到队尾；已受理/已确认项不可撤回、不可覆盖。
  - 组件状态（草稿/在途/已发布）完全由评审结论派生，不再手工切换。
- 发布快照与版本差异：发布快照只汇编窗口内评审通过的冻结结论（可复制 JSON）；版本差异页对照该组件最近一次生效结论，不读取草稿或在途内容。
- 版本差异：保存草稿快照后可比较字段、属性与示例变化；保留最近 12 个本地快照（本地快照不参与发布）。
- 主题与密度预览：支持浅色/深色，以及紧凑、标准、宽松三档密度。
- 代码示例复制与离线编辑：内容写入本地存储，刷新或断网后仍可继续编辑。
- 撤销重做：支持工具栏按钮，以及 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`。
- 键盘流程：`Cmd/Ctrl+K` 聚焦搜索，`Alt+1` 至 `Alt+6` 切换编辑区，`Alt+N` 新建组件，`Cmd/Ctrl+S` 保存草稿。

## 技术栈

- Lit 3
- TypeScript 5
- Spectrum Web Components
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认在源码配置的 Vite 端口运行，并监听 `0.0.0.0`。宿主机端口由项目根目录的 `docker-compose.yml` 统一映射为 `10028:80`。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1028 .
docker run --rm -p 10028:80 sologsb-1028
```

镜像采用 Node 多阶段构建，最终由 nginx 提供静态内容并监听容器 `80`。容器不硬编码宿主端口。

## 数据说明

浏览器存储键为 `sologsb-1028-workspace-v2`（首次加载会自动迁移 v1 草稿，评审数据从空开始）。清除站点数据会恢复到内置示例数据：2026 年 9 月窗口名额已满（通过、评审中、驳回各一项），另有一个带驳回记录与失效示例的草稿可用于体验整次拒绝流程。
